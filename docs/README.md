# SpatialBoard documentation

Suggested reading order:

1. **[getting-started.md](getting-started.md)** — install, render your first
   board, drive the engine, persist and restore.
2. **[design-philosophy.md](design-philosophy.md)** — the ideas the library is
   built on; read this before extending it.
3. **[custom-nodes.md](custom-nodes.md)** — the `NodeTypeDefinition` API end
   to end, with a worked example.
4. **[data-flow.md](data-flow.md)** — typed ports, `compute`, and the
   reactive `DataFlowEngine`.
5. **[agents.md](agents.md)** — LLM/agent integration: budgeted state
   snapshots, programmatic drawing, SBD read/write loops.
6. **[examples.md](examples.md)** — a guided path through `examples/`, from a
   minimal board to the full playground.
